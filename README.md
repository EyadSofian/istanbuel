# برنامج إسطنبول السياحي — صفحة هبوط (البكري أوفرسيز)

صفحة هبوط عربية RTL لبيع **برنامج إسطنبول السياحي** (7 ليالٍ / 8 أيام، من 28 أغسطس إلى 4 سبتمبر)
مع توجيه كل أزرار الحجز إلى واتساب.

الصفحة **HTML/CSS/JS خام** — من غير أي build أو تنصيب. ارفع الملفات على أي استضافة
(أو GitHub Pages / Netlify / Vercel) وهتشتغل على طول.

```
index.html                        الصفحة
assets/css/styles.css             التصميم
assets/js/content.js              ← كل البيانات القابلة للتعديل (ابدأ من هنا)
assets/js/main.js                 بناء الصفحة والتفاعلات
assets/img/logo.png               الشعار (كحلي — للناف بار)
assets/img/logo-light.png         الشعار (أبيض — للفوتر)
assets/img/favicon.png            أيقونة الموقع
assets/img/og-cover.jpg           كارت المشاركة على واتساب وفيسبوك
assets/img/hero/                  صورة/فيديو الهيرو
assets/img/hotel/                 صور الفندق (حقيقية)
assets/img/places/                صور توضيحية لأيام البرنامج
assets/img/reviews/               صور آراء العملاء ← لسه فاضي
vercel.json                       إعدادات النشر على فيرسل
scripts/build.js                  تجهيز مجلد dist/ وضبط روابط المشاركة
```

## 1) تعديل الأسعار والتواريخ والبرنامج

كل حاجة في ملف واحد: **`assets/js/content.js`**.
غيّر القيمة هناك، والصفحة كلها بتتحدّث لوحدها (الهيرو، كروت الأسعار، البوب أب، الأسئلة، بيانات SEO).

```js
const trip = {
  name: "برنامج إسطنبول السياحي",
  duration: "7 ليالٍ / 8 أيام",
  dateRange: "من 28 أغسطس إلى 4 سبتمبر",
  hotel: "HEYA HOTEL TAKSIM",
  whatsappNumber: "201225279820",
  startingPrice: 35000,
  discountPercent: 10,
  prices: {
    SGL:  { before: 50000, after: 45000 },
    DBL:  { before: 40778, after: 36700 },
    TRPL: { before: 38889, after: 35000 }
  },
  childrenPrices: { ... }
};
```

في نفس الملف كمان: البرنامج اليومي، جدول المقارنة، ما يشمله البرنامج، الأوراق المطلوبة،
والأسئلة الشائعة.

> **ملاحظة:** لو غيّرت التواريخ أو اسم البرنامج، عدّل كمان `<title>` و`<meta name="description">`
> في أول `index.html` — دول ثابتين عشان محركات البحث.

### إضافة يوم في البرنامج

```js
{
  day: "اليوم التاسع",
  title: "عنوان اليوم",
  items: [
    { text: "نشاط عادي." },
    { text: "نشاط اختياري.", optional: true },   // بيطلع شارة: اختياري – برسوم إضافية
    { text: "نشاط مشمول.",  included: true }     // بيطلع شارة: مشمولة في سعر البرنامج
  ]
}
```

## 2) الصور

الصفحة بتتأكد إن الصورة موجودة قبل ما تعرضها. لو الصورة مش موجودة بيظهر **مكان محجوز واضح**
مكتوب عليه اسمه — من غير أي صور وهمية أو مضللة.

### الموجود فعلاً

| المكان | الملفات | الحالة |
|---|---|---|
| الشعار | `logo.png` · `logo-light.png` · `favicon.png` | ✅ الشعار الرسمي |
| خلفية الهيرو | `hero/istanbul.jpg` | ✅ |
| صور الفندق | `hotel/facade.jpg` · `room.jpg` · `reception.jpg` · `breakfast.jpg` · `twin-room.jpg` · `lobby.jpg` | ✅ صور حقيقية لفندق HEYA |
| صور أيام البرنامج | `places/bosphorus.jpg` · `masukiye.jpg` · `princess-islands.jpg` · `ortakoy.jpg` | ✅ توضيحية |
| آراء العملاء | `reviews/review-01.jpg` … | ⬜ **ناقصة** |

### ⬜ آراء العملاء — محتاجة منك

سكرين شوت الآراء **مش موجودة** في ملف المشروع اللي اتبعت (كانت مجرد مؤشرات لملفات
على سيرفر Lovable مش صور فعلية). حط الصور في `assets/img/reviews/` بالأسماء
`review-01.jpg` … `review-06.jpg` وهتظهر تلقائياً مكان الأماكن المحجوزة.
لزيادة العدد عدّل مصفوفة `content.reviews` في `content.js`.

الصور بتتعرض **كاملة من غير أي قص** بارتفاعها الطبيعي، والضغط عليها بيفتحها مكبّرة.

### فيديو الهيرو (اختياري)

حط ملف باسم `assets/img/hero/istanbul.mp4` وهيشتغل صامت ومتكرر بدل الصورة.

### صور أيام البرنامج

كل يوم في `content.itinerary` يقدر ياخد `image`. الصور دي **معبّرة عن طابع المكان
مش لقطة حرفية لمَعلم بعينه** — لو عندك صور حقيقية من رحلاتكم استبدلها، ولو مش
عايز صورة لليوم امسح سطر `image` وخلاص.

## 3) أكواد التتبع (GTM و Clarity)

في أول `index.html` في بلوك جاهز — حط المعرّفات وبس:

```html
<script>
  window.SITE_TRACKING = {
    gtmId: "GTM-XXXXXXX",   // معرّف Google Tag Manager
    clarityId: "abcd1234"   // معرّف مشروع Microsoft Clarity
  };
</script>
```

طالما القيم فاضية، مفيش أي سكريبت تتبع بيتحمّل خالص.

كمان في `<body>` جزء **GTM noscript** مكتوب كتعليق — شيل علامات التعليق وحط المعرّف
بعد ما تفعّل GTM.

كل أزرار الحجز عليها `data-cta` (مثال: `hero` / `pricing` / `popup` / `fab`) عشان تقدر
تفرّق بين مصادر الضغطات في التقارير.

## 4) رقم الواتساب

اتغيّر من مكان واحد بس: `trip.whatsappNumber` في `content.js` (من غير `+` ولا مسافات).
رسالة الواتساب الجاهزة بتتبني تلقائياً من اسم البرنامج والتاريخ.

---

## 5) الشعار

الشعار الرسمي مستخدم في 3 نسخ، كلها مقصوصة ومظبوطة من ملف الشعار الأصلي:

- `assets/img/logo.png` — كحلي على خلفية شفافة (الناف بار)
- `assets/img/logo-light.png` — أبيض (الفوتر الكحلي وكارت المشاركة)
- `assets/img/favicon.png` + `apple-touch-icon.png` — علامة الـ B على مربّع كحلي

لو حدّثت الشعار، استبدل الملفات دي بنفس الأسماء والصفحة هتاخده على طول.

## 6) النشر على Vercel

المشروع مجهّز للنشر على فيرسل على طول — من غير أي إعدادات في الواجهة.

1. **New Project** → اربط الريبو `EyadSofian/istanbuel`.
2. فيرسل هيقرا `vercel.json` لوحده:
   - Build Command: `npm run build`
   - Output Directory: `dist`
3. **Domains** → ضيف الساب دومين بتاعك (مثال: `istanbul.yourdomain.com`)
   وحط عند مزوّد الدومين ريكورد `CNAME` على `cname.vercel-dns.com`.

### ⚠️ خطوة مهمة: متغيّر SITE_URL

في **Settings → Environment Variables** ضيف:

| Key | Value |
|---|---|
| `SITE_URL` | `https://istanbul.yourdomain.com` |

ليه ده مهم؟ لأن معاينة اللينك على واتساب وفيسبوك مبتشتغلش بروابط نسبية —
`scripts/build.js` بيستخدم القيمة دي عشان يحوّل وسوم `og:image` و`og:url`
و`canonical` لروابط كاملة وقت البناء.

لو مضفتهوش، البناء هينجح عادي والصفحة هتشتغل، لكن **صورة المعاينة مش هتظهر
لما حد يبعت اللينك على واتساب** — وده مهم جداً لأن كل الحجز ماشي على واتساب.
(لو نسيت، فيرسل بيحاول يستخدم دومين الإنتاج تلقائياً، بس تحديد `SITE_URL`
بنفسك أضمن.)

### صورة المعاينة

`assets/img/og-cover.jpg` (1200×630) — كارت المشاركة اللي بيظهر على واتساب.
فيه اسم البرنامج والتاريخ والسعر والشعار. لو غيّرت السعر أو التاريخ، استبدل
الصورة دي بواحدة محدّثة.

### بعد أي تعديل

اعمل push للبرانش، وفيرسل هينشر لوحده. ملفات `content.js` و`styles.css`
مضبوطة على `must-revalidate` فأي تعديل بيظهر فوراً من غير ما العميل يمسح الكاش.

## 7) تشغيل محلي

أي سيرفر ثابت يكفي:

```bash
npm run dev
# افتح http://localhost:8080
```

ولاختبار نسخة النشر بالظبط:

```bash
SITE_URL="https://istanbul.yourdomain.com" npm run build
cd dist && python3 -m http.server 8080
```
