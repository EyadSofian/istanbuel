# برنامج إسطنبول السياحي — صفحة هبوط (البكري أوفرسيز)

صفحة هبوط عربية RTL لبيع **برنامج إسطنبول السياحي** بـ**3 مواعيد للسفر**
(28 أغسطس، و7 سبتمبر، و7 أكتوبر) مع توجيه كل أزرار الحجز إلى واتساب.

الصفحة **HTML/CSS/JS خام** — من غير أي build أو تنصيب. ارفع الملفات على أي استضافة
(أو GitHub Pages / Netlify / Vercel) وهتشتغل على طول.

```
index.html                        الصفحة
assets/css/styles.css             التصميم
assets/js/content.js              ← كل البيانات القابلة للتعديل (ابدأ من هنا)
assets/js/main.js                 بناء الصفحة والتفاعلات
assets/img/logo.png               الشعار (كحلي — للناف بار)
assets/img/logo-light.png         الشعار (أبيض — للفوتر)
assets/img/favicon.png            أيقونة الموقع
assets/img/og-cover.jpg           كارت المشاركة على واتساب وفيسبوك
assets/img/hero/                  صورة/فيديو الهيرو
assets/img/hotel/                 صور الفندق (حقيقية)
assets/img/places/                صور توضيحية لأيام البرنامج
vercel.json                       إعدادات النشر على فيرسل
scripts/build.js                  تجهيز مجلد dist/ وضبط روابط المشاركة
```

## 1) تعديل الأسعار والتواريخ والبرنامج

كل حاجة في ملف واحد: **`assets/js/content.js`**.
غيّر القيمة هناك، والصفحة كلها بتتحدّث لوحدها (الهيرو، كروت الأسعار، البوب أب، الأسئلة، بيانات SEO).

`trip` متقسّم لجزئين: **حاجات مشتركة** بين كل المواعيد، و**مصفوفة `departures`**
فيها كل موعد بأسعاره ومواعيد طيرانه.

```js
const trip = {
  name: "برنامج إسطنبول السياحي",
  hotel: "HEYA HOTEL TAKSIM",
  whatsappNumber: "201225279820",
  discountPercent: 10,

  childrenPrices: { ... },        // أسعار الأطفال — واحدة لكل المواعيد

  departures: [                   // أول موعد هو اللي بيتفتح افتراضياً
    {
      id: "sep",                  // معرّف داخلي (حروف إنجليزي، من غير مسافات)
      tab: "سبتمبر",              // اسم التبويب
      dateRange: "من 7 إلى 15 سبتمبر",   // التاريخ الكامل (الهيرو والدعوة الأخيرة)
      dateShort: "7 – 15 سبتمبر",        // نسخة قصيرة (صندوق السعر)
      duration: "8 ليالٍ / 9 أيام",
      nights: 8,                  // بيظهر في قسم الفندق
      flights: {
        outbound: { depart: "15:05", arrive: "17:30" },   // الذهاب
        inbound:  { depart: "09:00", arrive: "11:05" }    // العودة
      },
      prices: {
        SGL:  { before: 50144, after: 45130 },
        DBL:  { before: 40422, after: 36380 },
        TRPL: { before: 37833, after: 34050 }
      }
    }
  ]
};
```

- **`before`** = السعر **قبل** خصم الـ10%، و**`after`** = السعر النهائي بعد الخصم.
  الصفحة بتحسب «توفّر كذا جنيه» لوحدها من الفرق بينهم.
- **`flights: null`** = مواعيد الطيران لسه ما تأكدتش، والكارت بيكتب إنها بتتأكد
  قبل السفر مع زر واتساب — بدل ما نعرض مواعيد مش مؤكدة.
- التوقيت بنظام 24 ساعة. عايزه بصيغة تانية (`3:05 م`)؟ اكتبه كده في `content.js`
  على طول — مفيش أي كود بيفكّ التوقيت أو بيعيد تنسيقه.
- **أقل سعر** في كل موعد (الغرفة الثلاثية) هو اللي بيظهر في التبويب وفي
  «السعر يبدأ من» في الهيرو وصندوق السعر والدعوة الأخيرة.

### إضافة موعد سفر جديد

انسخ أي عنصر كامل من `departures` وغيّر فيه `id` و`tab` والتواريخ والأسعار
ومواعيد الطيران — **وبس**. التبويب بيظهر في الصفحة لوحده، والضغط عليه بيحدّث
الأسعار وكارت الطيران والتاريخ والمدة ورسالة الواتساب في الصفحة كلها.

في نفس الملف كمان: البرنامج اليومي، ما يشمله البرنامج، آراء العملاء، الأوراق المطلوبة،
والأسئلة الشائعة.

> **ملاحظة:** لو غيّرت التواريخ أو اسم البرنامج، عدّل كمان `<title>` و`<meta name="description">`
> في أول `index.html` — دول ثابتين عشان محركات البحث. وكمان إجابات
> `content.faq` نص ثابت مش مربوط بالتبويب المختار (لأن بيانات SEO بتتحقن مرة
> واحدة وقت التحميل)، فلو ضفت موعد راجع الإجابات.

### إضافة يوم في البرنامج

```js
{
  day: "اليوم التاسع",
  title: "عنوان اليوم",
  items: [
    { text: "نشاط عادي." },
    { text: "نشاط اختياري.", optional: true },   // بيطلع شارة: اختياري – برسوم إضافية
    { text: "نشاط مشمول.",  included: true }     // بيطلع شارة: مشمولة في سعر البرنامج
  ]
}
```

## 2) الصور

الصفحة بتتأكد إن الصورة موجودة قبل ما تعرضها. لو الصورة مش موجودة بيظهر **مكان محجوز واضح**
مكتوب عليه اسمه — من غير أي صور وهمية أو مضللة.

### الموجود فعلاً

| المكان | العدد | الحالة |
|---|---|---|
| الشعار | 3 نسخ | ✅ الشعار الرسمي |
| خلفية الهيرو | 1 | ✅ |
| صور الفندق | 9 | ✅ صور حقيقية لفندق HEYA |
| صور أيام البرنامج | 13 | ✅ توضيحية |

كل صور المشروع اللي اتبعت اتحطّت، ما عدا:

- **`uludag.jpg`** — أولوداغ في **بورصة**، وإنت طلبت في الأول إن البورصة متتحطش،
  وكمان مفيش محطة في البرنامج تقابلها. لو عايزها، ضيفها لأي يوم في `content.itinerary`.

### آراء العملاء — نص مش صور

قسم الآراء بقى **كروت نصية** مش صور. اكتب الآراء في `content.reviews`:

```js
reviews: [
  { text: "نص الرأي زي ما العميل كتبه.", name: "اسم العميل",
    trip: "إسطنبول – أغسطس 2026" },   // trip اختياري
],
```

**المصفوفة فاضية دلوقتي، وعشان كده القسم كله مش ظاهر في الصفحة** — ولا كروت
فاضية ولا كلام مكتوب من عندنا. أول ما تحط أول رأي، القسم بيظهر لوحده
والرابط بتاعه بيرجع في القائمة.

### فيديو الهيرو (اختياري)

حط ملف باسم `assets/img/hero/istanbul.mp4` وهيشتغل صامت ومتكرر بدل الصورة.

### صور أيام البرنامج

كل يوم في `content.itinerary` بياخد مصفوفة `images` بتتعرض كشريط مصغّرات
والضغط عليها بيكبّرها.

```js
images: ["assets/img/places/bosphorus.jpg", "assets/img/places/balat.jpg"],
```

الصور دي **معبّرة عن طابع المكان مش لقطة حرفية لمَعلم بعينه** — وعشان كده
مفيش عليها أسماء معالم مكتوبة. لو عندك صور حقيقية من رحلاتكم استبدلها،
ولو مش عايز صور لليوم امسح سطر `images`.

## 3) أكواد التتبع (GTM و Clarity)

في أول `index.html` في بلوك جاهز — حط المعرّفات وبس:

```html
<script>
  window.SITE_TRACKING = {
    gtmId: "GTM-XXXXXXX",   // معرّف Google Tag Manager
    clarityId: "abcd1234"   // معرّف مشروع Microsoft Clarity
  };
</script>
```

طالما القيم فاضية، مفيش أي سكريبت تتبع بيتحمّل خالص.

كمان في `<body>` جزء **GTM noscript** مكتوب كتعليق — شيل علامات التعليق وحط المعرّف
بعد ما تفعّل GTM.

كل أزرار الحجز عليها `data-cta` (مثال: `hero` / `pricing` / `popup` / `fab`) عشان تقدر
تفرّق بين مصادر الضغطات في التقارير.

## 4) رقم الواتساب

اتغيّر من مكان واحد بس: `trip.whatsappNumber` في `content.js` (من غير `+` ولا مسافات).
رسالة الواتساب الجاهزة بتتبني تلقائياً من اسم البرنامج والتاريخ.

## 5) الشعار

الشعار الرسمي مستخدم في 3 نسخ، كلها مقصوصة ومظبوطة من ملف الشعار الأصلي:

- `assets/img/logo.png` — كحلي على خلفية شفافة (الناف بار)
- `assets/img/logo-light.png` — أبيض (الفوتر الكحلي وكارت المشاركة)
- `assets/img/favicon.png` + `apple-touch-icon.png` — علامة الـ B على مربّع كحلي

لو حدّثت الشعار، استبدل الملفات دي بنفس الأسماء والصفحة هتاخده على طول.

## 6) النشر على Vercel

المشروع مجهّز للنشر على فيرسل على طول — من غير أي إعدادات في الواجهة.

1. **New Project** → اربط الريبو `EyadSofian/istanbuel`.
2. فيرسل هيقرا `vercel.json` لوحده:
   - Build Command: `npm run build`
   - Output Directory: `dist`
3. **Domains** → ضيف الساب دومين بتاعك (مثال: `istanbul.yourdomain.com`)
   وحط عند مزوّد الدومين ريكورد `CNAME` على `cname.vercel-dns.com`.

### ⚠️ خطوة مهمة: متغيّر SITE_URL

في **Settings → Environment Variables** ضيف:

| Key | Value |
|---|---|
| `SITE_URL` | `https://istanbul.yourdomain.com` |

ليه ده مهم؟ لأن معاينة اللينك على واتساب وفيسبوك مبتشتغلش بروابط نسبية —
`scripts/build.js` بيستخدم القيمة دي عشان يحوّل وسوم `og:image` و`og:url`
و`canonical` لروابط كاملة وقت البناء.

لو مضفتهوش، البناء هينجح عادي والصفحة هتشتغل، لكن **صورة المعاينة مش هتظهر
لما حد يبعت اللينك على واتساب** — وده مهم جداً لأن كل الحجز ماشي على واتساب.
(لو نسيت، فيرسل بيحاول يستخدم دومين الإنتاج تلقائياً، بس تحديد `SITE_URL`
بنفسك أضمن.)

### صورة المعاينة

`assets/img/og-cover.jpg` (1200×630) — كارت المشاركة اللي بيظهر على واتساب.
فيه اسم البرنامج والتاريخ والسعر والشعار.

> ⚠️ **الصورة دي محتاجة تحديث دلوقتي.** التاريخ والسعر القديمين (28 أغسطس
> و35,000 جنيه) **محروقين جوه الصورة نفسها** ومش ممكن يتغيّروا من الكود.
> لحد ما تتستبدل بواحدة فيها الـ3 مواعيد والسعر الجديد (32,415 جنيه)،
> معاينة اللينك على واتساب هتفضل بتعرض البيانات القديمة.

### بعد أي تعديل

اعمل push للبرانش، وفيرسل هينشر لوحده. ملفات `content.js` و`styles.css`
مضبوطة على `must-revalidate` فأي تعديل بيظهر فوراً من غير ما العميل يمسح الكاش.

## 7) تشغيل محلي

أي سيرفر ثابت يكفي:

```bash
npm run dev
# افتح http://localhost:8080
```

ولاختبار نسخة النشر بالظبط:

```bash
SITE_URL="https://istanbul.yourdomain.com" npm run build
cd dist && python3 -m http.server 8080
```

## ملاحظات

- **أزرار الواتساب:** اتنين بس جوه الصفحة — واحد تحت السعر في الهيرو، وواحد في
  الدعوة الأخيرة. وكمان الزر العائم (ديسكتوب) / الشريط السفلي (موبايل) — دول
  عنصر واحد بيظهر حسب حجم الشاشة، والبوب أب اللي بيظهر مرة في الجلسة.
- **تبويبات المواعيد** جوه قسم الأسعار هي مصدر الحقيقة الوحيد: التبويب المختار
  بيحدّد الأسعار وكارت الطيران والتاريخ والمدة و«السعر يبدأ من» ورسالة الواتساب
  في الصفحة كلها. من غير جافاسكريبت الصفحة بتفضل مقروءة ببيانات أول موعد.
- الأقسام بتوزّع خلفياتها بالتبادل تلقائياً، فلو خبّيت قسم الترتيب بيتظبط لوحده.
- كل الألوان محصورة في متغيّرات CSS في أول `styles.css` (كحلي / أزرق / سماوي / أخضر واتساب).
- الصفحة متجاوبة من 320px لفوق، ومتوافقة مع `prefers-reduced-motion`، وفيها نسخة طباعة.
- البوب أب بيظهر بعد ثانيتين ومبيرجعش تاني في نفس الجلسة بعد ما يتقفل.
